Square Peg
Is the pricing/contract type mismatched to the nature of the work?
Minimal 2 quotes ▾
Reasoning
The solicitation is a Notice of Intent to sole-source a Firm-Fixed-Price contract for a software upgrade (HEYEX2/SPECTRALIS). This is a well-defined, discrete commercial software acquisition: the deliverable is a specific software upgrade, the vendor (L1 Enterprises) is already identified, and the scope is bounded. FFP is the appropriate contract type for a commercial software upgrade because: (1) the deliverable is clearly defined — an upgrade to an existing named software product; (2) the cost and schedule can be reasonably estimated by both the vendor and the government; and (3) there is no indication that scope will evolve unpredictably. The FAR guidance on FFP aligns well here — this is essentially a commercial product or product-adjacent transaction (software upgrade), where risk can be estimated with acceptable certainty. There is no mismatch between the contract type and the requirements. The solicitation does not describe open-ended labor or research tasks that would call for T&M or cost-reimbursement structures. This is a severity 1 finding — the contract type is appropriate for the requirement as described.
