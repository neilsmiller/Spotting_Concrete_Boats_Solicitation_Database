Square Peg

Reasoning
The Fixed Price ID/IQ structure is appropriate for this requirement. The core task — conducting compliance surveys at State Veterans Homes using a defined CMS methodology under a specific regulatory framework — is a well-characterized, repeatable service. Surveying a nursing home facility involves a known methodology, predictable labor categories (typically licensed clinical surveyors), and estimable durations. The ID/IQ structure appropriately handles variability in the number of surveys ordered across the performance period, while fixed pricing at the task order level is consistent with the nature of the work. There is no indication that the scope of any individual survey is open-ended or research-like in a way that would warrant T&M or cost-reimbursement. The fact that surveys are ordered via task orders also provides a natural mechanism for scoping each engagement individually. This is a reasonable match between contract type and requirements. The solicitation does not provide the full PWS, so a complete assessment is limited, but nothing in the available information suggests a significant mismatch. Severity is 1 — the contract type is defensible and appropriate given the context.
